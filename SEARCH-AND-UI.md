# Search and UI fixes

- Search requests up to 100 geocoding results and prefers Myanmar matches.
- Interactive results show the matching place and administrative area before loading weather.
- Burmese aliases cover common Myanmar city names.
- Layout, contrast, mobile spacing, input states and result dropdown were rebuilt.
- Open-Meteo geocoding is broad but not a guaranteed official complete township registry; a verified local place dataset is needed for every small village.
