မုန်တိုင်း / ရေကြီးသတိပေးချက်
၇ ရက် ရာသီဥတုခန့်မှန်းချက်
လာမည့် ၂၄ နာရီ · ၁ နာရီချင်း
ဒေတာတိကျမှုအကြောင်း
လက်ရှိအပူချိန်နှင့် forecast တန်ဖိုးများသည် အနီးဆုံး grid cell အတွက် high-resolution weather model data ဖြစ်ပြီး “တိုင်းတာရေးစခန်းက တိုင်းထားတဲ့ အတိအကျတန်ဖိုး” မဟုတ်ပါ။ မိုးရေချိန်၊ UV၊ AQI စသည်တို့အတွက် အနီးအနား station / radar / monitoring data ရှိပါက ထိုဒေတာက ပိုတိကျနိုင်ပါတယ်။ Forecast ကို နောက်ဆုံး update နဲ့ အမြဲပြန်ယူပေးထားပါတယ်။
Open-Meteo · ECMWF / NOAA / other model sources · Best Match
ရေရှည်အသုံးဝင်မှု
  • မိုးရေချိန်ကို ကြိုတင်ပြင်ဆင်သိရင် စိုက်ပျိုးရေး၊ ရေသိုလှောင်မှု၊ တောင်စောင်းစိုရွှဲမှုကို ကြိုတင်စောင့်ကြည့်နိုင်သည်။
  • ၂၄ နာရီမိုးရေချိန် ခန့်မှန်းချက်က ရေကြီးမှုအန္တရာယ်၊ မြစ်ကမ်းနားအန္တရာယ်၊ စီးပွားရေး ပျက်စီးမှုကို ကြိုတင်သတိပေးနိုင်သည်။
  • UV နှင့် AQI အချက်အလက်များက ကျန်းမာရေး၊ အနာတမီဒိတ်အတိုင်းအတာနှင့် လေ့လာမှုအတွက် ချက်ချင်းအသုံးဝင်သည်။
ရေကြီးနိုင်ချေသည် ကြိုတင်သတိပေးချက်အတွက် ၂၄ နာရီ မိုးရေချိန်ခန့်မှန်းချက်အပေါ် အခြေခံသော warning layer တစ်ခုသာဖြစ်ပြီး တရားဝင်နှင့်အတိအကျသော ရေကြီးမှုတိကျချက်အဖြစ် မယူဆပါနှင့်။ မုန်တိုင်း/ရေကြီးမှု ဖြစ်စဉ်များကို NASA EONET မှ ထပ်ဆောင်းပြသထားပါသည်။
